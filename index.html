Web Search

Ranked results from the live web, with the passage that answers the query.

  • Highlightsdefault Only the passages that answer the query, so whole pages never pad your context window.
  • Full page content The complete text of each page, stripped of navigation and ads.
  • Page images Cover and inline images from each result, each with a description.
  • Source filters Results limited to the domains, language, or time window you choose.
Playground Docs

Broad Search

Splits one question into sub-queries, searches them at once, and groups what comes back.

  • Grouped results Results returned under the sub-query that found them.
  • Shared filters One set of parameters applied to every sub-query at once.
  • Full content Cleaned page text for the results of every sub-query.

Image Search Early Access

Images from the open web, by text query or by reference image.

  • Text query Images from across the web, each with its source page and a description.
  • Reference image Start from an image and get visually similar ones back.
  • Design mode A style summary and a reusable HTML snippet for each result.
  • Source filters Images limited to the domains you choose.

Video Search Early Access

Videos from the open web, with the metadata to preview or embed them.

  • Text query Videos with source page, cover image, duration, and publish time.

Common questions

It lets software query the live web and get structured results back, with no browser or scraping. Octen is built for LLMs and agents: results arrive as ranked highlights with timestamps and source URLs, ready to drop into a model's context.
A SERP API scrapes a search engine and returns links and snippets — you still fetch and clean each page. Octen queries its own live index and returns the content itself: ranked, extracted, model-ready. One call replaces search plus crawl.
Compare on public benchmarks within the same latency class. Among fast-tier search APIs, Octen leads on SimpleQA at 95.2% and FreshQA Strict at 55.8%, ahead of Exa, Parallel, and Tavily, at 62ms P50.
