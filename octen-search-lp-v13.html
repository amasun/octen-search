Common questions

What is a web search API?
It lets software query the live web and get structured results back, with no browser or scraping. Octen is built for LLMs and agents: results arrive as ranked highlights with timestamps and source URLs, ready to drop into a model's context.
How is it different from a SERP API?
A SERP API scrapes a search engine and returns links and snippets — you still fetch and clean each page. Octen queries its own live index and returns the content itself: ranked, extracted, model-ready. One call replaces search plus crawl.
Which web search API gives the best results?
Compare on public benchmarks within the same latency class. Among fast-tier search APIs, Octen leads on SimpleQA at 95.2% and FreshQA Strict at 55.8%, ahead of Exa, Parallel, and Tavily, at 62ms P50.
When should I use Broad Search instead of Web Search?
Web Search for a single lookup: a fact, a price, a page. Broad Search when one question has several angles, like comparisons or research. Same parameters, same result fields — returned grouped by sub-query.

Both are in Early Access. Write to support@octen.ai and an existing key covers them once enabled.
